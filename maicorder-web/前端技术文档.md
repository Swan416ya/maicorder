# 前端技术文档

## 1. 项目概述

Maicorder 前端系统是一个基于 Vue 3 的单页应用（SPA），采用 Vite 作为构建工具，使用 Vue Router 进行路由管理，Axios 进行 HTTP 请求，Element Plus 作为 UI 组件库。系统实现了用户登录注册、签到管理、游戏记录等功能，为用户提供友好的交互界面。

## 2. 技术栈

| 技术/框架 | 版本 | 用途 |
|---------|------|------|
| Vue | 3.5.27 | 前端框架 |
| Vite | 7.3.1 | 构建工具 |
| Vue Router | 4.6.4 | 路由管理 |
| Axios | 1.13.2 | HTTP 请求 |
| Element Plus | 2.13.1 | UI 组件库 |
| @vitejs/plugin-vue | 6.0.4 | Vite Vue 插件 |

## 4. 核心功能模块

### 4.1 用户认证模块

用户认证模块负责用户的登录和注册功能，通过后端 API 进行身份验证，使用 JWT Token 进行会话管理。

**主要功能：**
- 用户登录：输入用户名和密码，验证成功后获取 JWT Token
- 用户注册：创建新用户账号
- 会话管理：使用 localStorage 存储 Token 和用户信息
- 路由守卫：保护需要认证的页面

**认证流程：**
1. 用户在登录页面输入用户名和密码
2. 前端发送登录请求到后端 API
3. 后端验证用户信息，返回 JWT Token
4. 前端将 Token 存储到 localStorage
5. 后续请求携带 Token 进行身份验证
6. 路由守卫检查 Token，未登录用户自动跳转到登录页

### 4.2 签到管理模块

签到管理模块是系统的核心功能，负责用户在街机厅的签到记录、费用管理和游戏记录。

**主要功能：**
- 选择机厅：从机厅列表中选择要签到的机厅
- 记录费用：记录游戏投币、餐饮、饮品、交通等费用
- 添加游戏场次：支持多种游戏类型（舞萌 DX、中二节奏、音击、IIDX）
- 记录战绩：记录每个游戏场次的具体战绩，包括曲名、分数、通关状态
- 提交记录：将签到信息提交到后端保存

**签到流程：**
1. 用户在主页面点击"勤了"按钮
2. 打开签到对话框，选择机厅和日期
3. 填写各项费用信息
4. 添加游戏场次，记录游戏类型和游玩 PC 数
5. 为每个游戏场次添加战绩记录
6. 提交签到记录到后端
7. 提交成功后关闭对话框，返回主页面

### 4.3 机厅管理模块

机厅管理模块负责机厅信息的展示，用户可以查看所有可用的机厅列表。

**主要功能：**
- 获取机厅列表：从后端获取所有机厅信息
- 显示机厅信息：在签到对话框中展示机厅列表供用户选择

## 6. API 接口文档

### 6.1 用户相关接口

#### 6.1.1 登录接口

**接口路径：** `POST /api/login`

**请求参数：**
```json
{
  "username": "string",  // 用户名
  "password": "string"   // 密码
}
```

**响应参数：**
```json
{
  "code": 200,           // 响应码
  "message": "操作成功",  // 响应信息
  "data": {
    "token": "string",   // JWT Token
    "user": {
      "id": 1,           // 用户ID
      "username": "string", // 用户名
      "email": "string"    // 邮箱
    }
  }
}
```

**错误响应：**
- 400: 用户名或密码不能为空
- 401: 用户名不存在或密码错误

**前端调用示例：**
```javascript
const response = await axios.post(`${API_BASE}/login`, {
  username: authForm.value.username,
  password: authForm.value.password
})
const result = response.data
if (result.code === 200 && result.data.token) {
  localStorage.setItem('token', result.data.token)
  localStorage.setItem('currentUser', JSON.stringify(result.data.user))
  axios.defaults.headers.common['Authorization'] = `Bearer ${result.data.token}`
  await router.push('/main')
}
```

## 7. 路由配置

### 7.1 路由结构

**配置文件：** `src/router/index.js`

**路由列表：**

| 路径 | 名称 | 组件 | 认证要求 | 说明 |
|-----|------|------|---------|------|

| `/login` | Login | LoginLayout | 否 | 登录页面 |
| `/main` | Main | MainLayout | 是 | 主页面 |

### 7.2 路由守卫

**守卫逻辑：**
```javascript
router.beforeEach((to, from, next) => {
  const token = localStorage.getItem('token')
  const requiresAuth = to.meta.requiresAuth

  if (requiresAuth && !token) {
    // 未登录，跳转到登录页
    next('/login')
  } else if (!requiresAuth && token && to.path === '/login') {
    // 已登录，访问登录页自动跳转到主页面
    next('/main')
  } else {
    next()
  }
})
```

**守卫说明：**
- 需要认证的页面（`requiresAuth: true`）未登录时自动跳转到登录页
- 已登录用户访问登录页时自动跳转到主页面
- 其他情况正常放行

## 8. 工具类和 API 请求封装

### 8.1 request.js

**文件路径：** `src/utils/request.js`

**功能描述：** 封装 Axios 实例，统一配置 API 请求，包括基础路径、超时时间、请求拦截器和响应拦截器。

**配置项：**
```javascript
const request = axios.create({
  baseURL: API_BASE,              // API 基础路径
  timeout: 10000,                 // 超时时间 10 秒
  headers: {
    'Content-Type': 'application/json'
  }
})
```

**请求拦截器：**
```javascript
request.interceptors.request.use(
  (config) => {
    const token = localStorage.getItem('token')
    if (token) {
      config.headers.Authorization = `Bearer ${token}`
    }
    return config
  },
  (error) => Promise.reject(error)
)
```

**拦截器说明：**
- 自动从 localStorage 获取 Token
- 将 Token 添加到请求头 `Authorization` 字段
- 使用 Bearer Token 格式

**响应拦截器：**
```javascript
request.interceptors.response.use(
  (response) => response.data,
  (error) => {
    const errMsg = error.response?.data?.message || error.message || '请求失败'
    alert(errMsg)
    return Promise.reject(error)
  }
)
```

**拦截器说明：**
- 成功响应直接返回响应体，简化业务代码
- 失败响应统一错误处理，显示错误提示
- 从响应数据中提取错误信息并提示用户

### 9.1 vite.config.js

**文件路径：** `vite.config.js`

**配置内容：**
```javascript
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import path from 'path'

export default defineConfig({
  plugins: [vue()],
  resolve: {
    alias: {
      '@': path.resolve(__dirname, 'src')
    }
  },
  server: {
    port: 8081, // 固定前端端口为8081
    open: true,
    // 代理配置：把前端/api请求转发到后端8080
    proxy: {
      '/api': {
        target: 'http://localhost:8080',
        changeOrigin: true,
        secure: false
      }
    }
  }
})
```

**配置说明：**
- `plugins`: 使用 Vue 插件
- `resolve.alias`: 配置路径别名，`@` 指向 `src` 目录
- `server.port`: 开发服务器端口为 8081
- `server.open`: 自动打开浏览器
- `server.proxy`: API 代理配置，将 `/api` 请求转发到后端 8080 端口

## 13. 安全性

### 13.1 XSS 防护

- 使用 Vue 的模板自动转义功能
- 避免使用 `v-html` 指令
- 对用户输入进行验证和过滤

### 13.2 CSRF 防护

- 使用 JWT Token 进行身份验证
- Token 存储在 localStorage 中
- 请求时在 Header 中携带 Token

### 13.3 敏感信息保护

- 不要在前端存储敏感信息
- 使用 HTTPS 协议传输数据
- 定期更新 Token

## 15. 常见问题

### 15.1 开发环境 API 请求失败

**问题：** 开发环境中 API 请求失败，提示跨域错误。

**解决方案：**
1. 确认后端服务已启动
2. 检查 `vite.config.js` 中的代理配置
3. 确认 API 请求路径正确

### 15.2 构建后页面空白

**问题：** 构建后部署到服务器，页面显示空白。

**解决方案：**
1. 检查服务器配置是否正确
2. 确认静态资源路径是否正确
3. 检查浏览器控制台是否有错误信息

### 15.3 Token 过期

**问题：** 用户操作时提示 Token 过期。

**解决方案：**
1. 实现 Token 刷新机制
2. 提示用户重新登录
3. 在响应拦截器中统一处理 Token 过期
